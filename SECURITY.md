# Security

Found a way to break JuicyJuicy (the site, the CLI, the skill or the Action), or a game that harms players? Report it privately with **[Report a vulnerability](https://github.com/githubvoyage/juicyjuicy/security/advisories/new)** on this repository. Please don't open a public issue for it.

Say what you found, how to reproduce it and what it lets someone do. We reply within a week, keep you posted while we fix it, and credit you when it's fixed if you'd like. The full policy: [juicyjuicy.games/docs/security](https://juicyjuicy.games/docs/security).
